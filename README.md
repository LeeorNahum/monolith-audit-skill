# Monolith Audit

Manual-only Agent Skill for thinking a piece of work through before it is built, or examining one that already exists. It grounds in the real work, forms an opinion against the whole the work belongs to, pushes back where it can name a real failure, hunts for problems and the fix for each, and puts every real decision to you one question at a time. The work can be software or any other deliverable.

Invoke it explicitly by name, with an idea, a plan, existing work, or nothing at all. It has its plan and findings judged by sessions that did not produce them, and it ends in a short brief you can hand to whoever implements. It does not carry out the implementation.

Files:

- `SKILL.md` is the methodology.
- `AGENTS.md` is the maintenance contract.
